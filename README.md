# Angular CartService на RxJS

Учебный Angular-проект: корзина товаров на `BehaviorSubject`.

## Запуск

1. Установи Node.js LTS.
2. Открой эту папку в VS Code.
3. Открой терминал в папке проекта.
4. Выполни команды:

```bash
npm install
npm start
```

5. Открой адрес, который покажет Angular CLI (обычно http://localhost:4200).

## Что реализовано

- `BehaviorSubject<CartItem[]>` хранит текущее состояние корзины.
- `getValue()` получает текущий список товаров.
- `next()` публикует обновлённое состояние.
- `asObservable()` предоставляет поток `cartItems$`.
- `async` pipe отображает обновления в шаблоне.
- Добавление товаров, увеличение количества, удаление и очистка корзины.

Это самостоятельный демонстрационный проект. Если преподаватель требует сохранить методы из исходного проекта урока, их нужно сверить с оригинальным `CartService`.
